# ШкафеLLA — Инструкция по запуску

## Что получишь
- 📱 **index.html** — форма заявки для клиентов (устанавливается на телефон/ноутбук)
- 🖥️ **admin.html** — панель всех заявок (статусы, фильтры, файлы)
- 📊 Заявки автоматически пишутся в **Google Таблицу** (Лист6)
- 💾 Файлы хранятся в **Firebase Storage**
- 🔄 Обновления в реальном времени

---

## ШАГ 1 — Google Apps Script (5 мин)
*Нужен чтобы заявки попадали в твою Google Таблицу*

1. Открой **https://script.google.com**
2. Нажми **«Новый проект»**
3. Удали весь код по умолчанию
4. Скопируй и вставь код из файла **google_apps_script.js**
5. Нажми 💾 **Сохранить** (Ctrl+S), дай любое имя
6. Нажми **«Развернуть»** → **«Новое развертывание»**
7. Тип: **Веб-приложение**
8. Выполнять как: **Я**
9. Доступ: **Все** (в том числе анонимные)
10. Нажми **«Развернуть»** → скопируй URL вида:
    `https://script.google.com/macros/s/XXXXXXXX/exec`

11. Открой **index.html** в текстовом редакторе
12. Найди строку: `const GAS_URL = 'YOUR_APPS_SCRIPT_URL';`
13. Замени `YOUR_APPS_SCRIPT_URL` на скопированный URL
14. Сохрани файл

---

## ШАГ 2 — Firebase (10 мин)
*Нужен для хранения файлов и панели admin.html*

1. Открой **https://console.firebase.google.com**
2. **«Создать проект»** → название (например: `shkafella`) → Создать
3. В меню: **Firestore Database** → «Создать» → Тестовый режим → регион `europe-west3`
4. В меню: **Storage** → «Начать» → Тестовый режим
5. ⚙️ Настройки → **«Ваши приложения»** → иконка `</>` → зарегистрировать
6. Скопируй блок `firebaseConfig`
7. Вставь его в **index.html** и **admin.html** (в обоих файлах есть метка `⚠️ ВСТАВЬ`)

---

## ШАГ 3 — Опубликовать на Vercel (5 мин)

1. Открой **https://vercel.com** → войди через GitHub (или email)
2. **«Add New Project»** → вкладка **«Upload»**
3. Перетащи папку `shkafella` целиком
4. Нажми **Deploy**
5. Через минуту получишь URL вида `shkafella.vercel.app`

**Готово!**
- `shkafella.vercel.app` → форма для клиентов
- `shkafella.vercel.app/admin.html` → твоя панель

## Проверка что всё работает

1. Открой форму → заполни тестовую заявку → отправь
2. Проверь **Лист6** в твоей Google Таблице — должна появиться строка
3. Открой `admin.html` — должна появиться карточка заявки

## Шаг 1 — Firebase (та же база что для мессенджера!)

Если уже создавал Firebase для мессенджера — **используй тот же проект**.
Просто создай новую коллекцию `orders` (она создастся автоматически при первой заявке).

Если нет — создай по инструкции из файла `ИНСТРУКЦИЯ.md` мессенджера.

---

## Шаг 2 — Вставить настройки Firebase

В файлах **index.html** и **admin.html** найди блок:
```
⚠️  ВСТАВЬ СВОИ НАСТРОЙКИ FIREBASE СЮДА
```
И замени `firebaseConfig` на свой (из Firebase Console → Настройки проекта).

> Важно: вставить нужно В ОБА файла!

---

## Шаг 3 — Правила Firestore

В Firebase Console → Firestore → Правила добавь коллекцию orders:

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /clients/{clientId} {
      allow read, write: if true;
      match /subchats/{subchatId}/messages/{msgId} {
        allow read, write: if true;
      }
    }
    match /orders/{orderId} {
      allow read, write: if true;
    }
  }
}
```
